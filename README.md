# Cafe Landing Template

Reusable landing page template for small cafes.

Live demo: https://mtsogtbayar24-alt.github.io/cafe-landing-template/

## Features

- Hero section with business name, tagline, and order CTA
- Menu grid rendered from a JS config
- Order form with validation (name required, 8-digit phone)
- Mobile-first, responsive layout

## Customize for a new client

Edit `script.js` — change only the `CONFIG` object:

- `businessName` — cafe name
- `phone` — contact phone
- `menu` — items with name and price in ₮

No build step. Open `index.html` or deploy with GitHub Pages.
